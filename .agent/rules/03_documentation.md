# ドキュメント

## ドキュメントの作成

- リポジトリ内の運用ドキュメントは `docs/` に Markdown で置いてください（ドキュメントサイトは現状ありません）。
- リリース手順や鍵の扱いなど、CI に関わる変更をしたときは `docs/releasing.md` を必ず更新してください。
- なお、文章の文体について、その他の部分で指示があったとしても、ドキュメントに関しては、あくまでも指示された文章の文体で記載してください。

## Storybook

- 新しい UI コンポーネントを作成した際は、`packages/ui/src/` に対応する `*.stories.tsx` ファイルを作成し、Storybook 上で確認できるようにしてください。
- アプリ固有の画面は Storybook の対象外です。共有 UI のみカタログ化します。
